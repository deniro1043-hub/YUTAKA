# yutaka

英単語を選択すると、日本語の意味がすぐに表示される Web ページです。

## 使い方

1. `index.html` をブラウザで開きます。
2. 英文の中の単語を、マウスでドラッグして選択します。
3. 単語の近くに、日本語の意味が表示されます。

## 仕組み

- 単語を選ぶと、Google 翻訳（英語→日本語）を開くリンクが表示されます。APIキーは不要です。
- 英単語 1 つだけに反応します。長い文章を選択した場合は表示されません。
- 翻訳を見るには、インターネット接続が必要です。

## 注意

- 翻訳の精度は完璧ではありません。文脈によって意味が変わる単語は、辞書でも確認してください。
- 文脈によって意味が変わる単語は、翻訳結果の例文も合わせて確認してください。
