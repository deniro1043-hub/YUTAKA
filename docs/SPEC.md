## 1. プロジェクト概要

### 1.1 アプリ名
かくれ漢字

### 1.2 ジャンル
- 漢字発見ゲーム
- 右脳トレーニング
- 図鑑収集ゲーム
- キャラクター育成ゲーム

### 1.3 コンセプト
プレイヤーは漢字の画（ストローク）を1本ずつ選択し、漢字の中に隠れている別の漢字を発見していく。

一般的な漢字学習アプリのような「読む・書く・テストする」ではなく、
観察力・パターン認識力・空間認識力・記憶力・集中力を育てる右脳型漢字パズルゲームとして設計する。

### 1.4 本ゲームの定義
かくれ漢字は漢字学習アプリではない。本質は

画を選ぶ → 漢字を発見する → 図鑑を埋める → キャラクターを育てる

という体験である。

## 6. 漢字描画仕様

### 6.1 採用データ
AnimCJK 日本語版 https://github.com/parsimonhi/animCJK

### 6.2 採用理由
AnimCJKは1画ごとに分離されたSVGを持つため、タップ判定・色変更・発見演出を実現できる。

### 6.3 使用方針
ゲーム内漢字は全てAnimCJKを利用して描画する。Text Widgetによる漢字表示は禁止。

- 禁止例：`Text("森")`
- 採用方式：AnimCJK SVG → Flutter描画 → 画単位制御

### 6.4 描画順
選択中の画は必ず最前面へ描画する。（未選択画 → 選択画）

## 9. ゲームループ

### 9.1 基本ループ
漢字表示 → 画をタップ → 画を選択 → 部品判定 → 漢字発見 → 図鑑登録 → クリア

## 10. 部品判定方式

### 10.1 基本方針
全て事前登録データにより判定する。リアルタイム推論は行わない。

### 10.2 判定単位
strokeIds

### 10.3 データ形式

```json
{
  "name": "木",
  "strokePatterns": [
    [1, 2, 3, 4]
  ]
}
```

## 11. 部品判定ルール

### 11.1 実在する漢字のみ採用
- 正解：木・林・森
- 不正解：木の半分、部首のみ

### 11.2 学年制限
- 1年生ステージ：1年生漢字のみ
- 2年生ステージ：1年生＋2年生漢字
- 3年生ステージ：1年生＋2年生＋3年生漢字
- 以下同様

### 11.3 字そのものも正解
例：木 → 木、森 → 森

### 11.4 画の重複利用を認める
森 → 木・林・森 すべて成立

### 11.5 同じ部品名は1回のみ
出 に山が複数存在しても、山 は1回だけ登録

### 11.6 複数箇所の同一部品
どこを選んでも正解（例：亀の日）

## 12. 一・二・三ルール
- 12.1 一：横線1本 → 成立
- 12.2 二：横線2本 → 成立
- 12.3 三：横線3本 → 成立

## 13. 十ルール
- 13.1 成立条件：縦線1本＋横線1本
- 13.2 例：土 → 十 成立

## 14. 折れ線ルール
- 14.1 基本方針：折れ線は 一 でも 丨 でもない
- 14.2 不成立例：口のコ部分 → 一 不成立
- 14.3 不成立例：日のコ部分 → 一 不成立
- 14.4 成立例：口・日・山 等。完成した漢字そのものとして成立する場合のみ有効
- 14.5 例外：（Ver.1.2 で削除）水の「小」は採用しない。

## 15. 曲線・斜線ルール
- 15.1 基本方針：採用する。
- 15.2 例：月の左払い → 縦線として扱う。その結果 口・日・目 が成立可能

## 16. 長すぎる線ルール
- 16.1 基本方針：採用しない。
- 16.2 不成立例：五 → 口 不成立
- 16.3 不成立例：円 → 口 不成立

## 17. 同一構成除外ルール
- 17.1 基本方針：同一画選択になる部品は片方を除外する。
- 17.2 例：出 → 山・小 が同じ選択結果 → どちらか一方のみ採用

## 18. ヒント機能
- 18.1 使用回数：1文字につき最大2回
- 18.2 ヒント1：残り発見数表示（例：あと3個あるよ）
- 18.3 ヒント2：未発見漢字の最初の画を光らせる

## 19. コインシステム
- 19.1 初回クリア：＋1コイン
- 19.2 再クリア：＋1コイン
- 19.3 例外：1〜4画の漢字 → コインなし
- 19.4 用途：ヒント利用

## 20. メダルシステム
- 20.1 判定基準：学年達成率
- 20.2 銅メダル：20% / 40%
- 20.3 銀メダル：60% / 80%
- 20.4 金メダル：100%
- 20.5 計算対象：1年生80字・2年生160字・3年生200字・4年生202字・5年生193字・6年生191字

## 21. メダル報酬
メダルでキャラクターカスタマイズ要素を解放する。（例：帽子・服・アクセサリー・背景・羽）

## 22. キャラクター育成
- 22.1 初期選択：モフ・ツノリン・プニタ
- 22.2 成長段階：たまご → こども → 成長 → 大人
- 22.3 成長条件：メダル獲得
- 22.4 ごはん：1文字クリア → ごはん＋1
- 22.5 効果：喜ぶ・表情変化・会話変化
- 22.6 制限：成長には影響しない。死ぬ要素なし。減点なし。罰なし。

## 23. 右脳トレーニング要素
独立モードにはしない。通常ゲーム内ギミックとして実装する。

- 23.1 シルエット：問題開始時に短時間表示
- 23.2 左右反転：Mirror Stage
- 23.3 上下反転：Flip Stage
- 23.4 発見済みフェード：発見した画を半透明化
- 23.5 記憶ステージ：輪郭のみ表示
- 23.6 スポットライト：一部分のみ表示
- 23.7 タイムアタック：制限時間付き

## 28. 実装優先順位
- Phase1：AnimCJK描画・ストローク描画・ストロークタップ
- Phase2：判定エンジン・ストロークマッチ判定・発見演出
- Phase3：ゲームループ・図鑑登録・クリア判定
- Phase4：コイン・ヒント・達成率
- Phase5：メダル
- Phase6：キャラクター育成
- Phase7：課金・iOS・Windowsリリース

## 29. 用語定義
- 問題漢字：出題される漢字
- 部品漢字：問題漢字の中から発見する漢字
- ストローク：1画
- 選択ストローク：プレイヤーが選択した画
- ストロークパターン：正解となる画の組み合わせ

## 30. 最重要実装事項
AI・人間を問わず最優先で実装するもの

1. AnimCJK描画
2. ストローク選択
3. ストロークパターン判定
4. 部品漢字発見
5. 図鑑登録

その後、コイン・ヒント・メダル・キャラクター育成・課金を実装する。
